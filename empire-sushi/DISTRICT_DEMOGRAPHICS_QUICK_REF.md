# Quick Reference: District Demographics Feature

## Tab Panel (Top of Right Panel)
```
┌────────────────────────────────────────────────────────┐
│  [Brand Analytics]  [District Demographics]           │
└────────────────────────────────────────────────────────┘
```

## Brand Analytics View (Original)
- Market share pie chart
- Store count by state
- Stores per district
- Brand performance radar
- Competitive areas
- Mall presence
- Market gap analysis
- Saturation score
- Top contested stores

## District Demographics View (New)

### When No District Selected:
```
        Click on a district or use dropdown
                  ↓
              [Map icon]
           Select a district
```

### When District Selected:

**Left Column:**
1. **Overview Card**
   - District name & state
   - Total population with icon
   - "495.3k population (2024)"

2. **Population Trend** (Line Chart)
   - Years: 2020-2024
   - Shows growth over time
   - Growth % calculation

3. **Ethnicity Breakdown** (Pie Chart)
   - Bumi Malay
   - Chinese
   - Indian
   - Other ethnicities
   - Interactive tooltips

**Right Column:**
1. **Age Distribution** (Bar Chart)
   - All age groups: 0-4, 5-9, ... 85+
   - Horizontal bars
   - Scrollable if needed

2. **Detailed Breakdown Table**
   - Each ethnicity listed
   - Population (k) and %
   - Scrollable

3. **Insights Card**
   - Highlights dominant ethnicity
   - Contextual information

## User Interactions

### To View District Demographics:
1. **Method 1**: Click on any district on the map
   - Automatically switches to Demographics tab
   - Shows selected district data

2. **Method 2**: 
   - Click "District Demographics" tab
   - Select district from dropdown

### To Return to Brand Analytics:
- Click "Brand Analytics" tab

## Map Features
- **Hover**: Cursor changes to pointer over districts
- **Click**: Selects district & shows demographics
- **Choropleth**: Still shows Population/Income coloring
- **Markers**: Store locations remain visible

## Data Available
- **160 districts** across Malaysia
- **5 years** of data (2020-2024)
- **Demographics**: Age, ethnicity, sex breakdowns
- **Population**: In thousands (k)

## Color Coding
- **Charts**: Various colors for different categories
- **Empire Red**: #c62828 (primary accent)
- **Blue tones**: #2563eb (demographics)
- **Green, Orange, Purple**: Additional categories
